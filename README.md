An interactive, web-based Linux desktop operating system portfolio built for **Benher Basheer**. Features multi-window management, custom bash terminal shell, security lab dashboard, background music player, system telemetry monitor, and complete touch responsiveness for mobile devices.

🔗 **Live Portfolio Site**: [https://linux.benherbasheer.me](https://linux.benherbasheer.me)

---

## ✨ Features

- 🖥️ **Multi-Window Operating System**: Draggable, minimizable, maximizable, and resizable window manager with glassmorphism visual design system and customizable accent colors.
- 💻 **Interactive Linux Shell (Terminal)**: Functional CLI supporting virtual filesystem traversal, commands (`help`, `ls`, `cat`, `whoami`, `projects`, `skills`, `clear`, `sudo`, `matrix`, `neofetch`, `theme`, `date`, `syslog`).
- 🎵 **NinjaOS Audio & Music Player**: Background MP3 track player featuring spinning vinyl visualizers, volume controls, rewind/fast-forward 10s seeking, and a floating draggable popover.
- 🛡️ **Security Lab App**: Live security posture telemetry, vulnerability scanner simulation, and HTTP header hardening reports.
- 📊 **System Monitor App**: Real-time CPU, RAM, and storage utilization gauges along with active process management table.
- 💼 **Career & Project Apps**: Interactive memory showcases for Experience, Technical Projects, Skills Matrix, Certifications (Java Fullstack), Resume, and Network Contact forms.
- 📱 **Full Mobile & Touch Optimization**: Mobile viewport auto-fitting, centered window positioning, smooth 1:1 touch-dragging, and compact tab bar taskbar.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### Local Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/benherr/linux-portfolio.git
   cd linux-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001).

---

## 🏗️ Production Build

To test or generate the optimized production build:

```bash
npm run build
npm run start
```
